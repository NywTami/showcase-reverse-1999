# Reverse: 1999 Character Gallery

Galeri web untuk menampilkan karakter, icon, costume, dan asset Live2D dari Reverse: 1999.

## Status

**Work in Progress (WIP)**

Project belum selesai. Struktur data, tampilan, daftar karakter, dan fitur masih dalam pengembangan.

## Isi Project

- Folder karakter berisi icon, costume, dan asset Live2D.
- `style.css` berisi styling antarmuka.
- `character_icons.csv` berisi data icon karakter.
- Script PowerShell membantu proses generate dan build data.
